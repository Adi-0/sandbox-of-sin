Circuit Analysis · Part 3 NCEES 6.D 24 minute read

Node and Loop Analysis

The method that never needs cleverness. It works on every linear circuit, including the ones where Part 2's shortcuts have nothing to grab — and the system it produces is the matrix from Mathematics Part 5, read straight off the drawing.

3.1 When the shortcuts run out

Part 2's technique needs a series or parallel group to collapse. Draw a bridge — four resistors in a diamond with a fifth across the middle — and there is not one. No two share both nodes, so nothing is in parallel; every junction has three branches, so nothing is in series. Every shortcut you have fails on the first step.

What is needed is a procedure that does not depend on the shape of the network at all. There are two, they are the same idea applied to the two laws in turn, and between them they cover everything on this exam.

3.2 Node analysis

Pick one node and declare it the reference — ground, zero volts. Every other node now has an unknown voltage. Write KCL at each of those unknowns, express each branch current as ΔV/R, and solve.

3.3 The matrix you can read off the drawing

Do that on a two-node circuit and something worth noticing happens. The equations always arrange themselves into the same shape:

G V = I

with G = 1/R as always. And each entry has a plain meaning you can read directly off the circuit:

  • Diagonal entry — the sum of all conductances touching that node. Always positive.
  • Off-diagonal entry — minus the conductance between those two nodes. Always negative, and always symmetric.
  • Right-hand side — the current pushed into that node by sources.

That means you can write the matrix without doing any algebra at all. Turn the knob in Plate 29 and watch the entries move as the circuit changes.

Mathematics Part 5 comes back

This is Ax = b, and Cramer's rule solves it in two determinants. The conductance matrix is always symmetric for a network of resistors, and it is singular exactly when you forgot to pick a ground — because without a reference the node voltages are only defined up to a constant, so no unique solution exists. A zero determinant here is a modelling mistake, not an arithmetic one.

3.4 Mesh analysis

The mirror image. Instead of node voltages, assume a circulating mesh current in each window of the circuit, then write KVL round each window. Where two meshes share a resistor, the current in it is the difference of the two mesh currents — which is the step people forget.

3.5 Choosing between them

Both always work. On a timed exam, pick the one with fewer unknowns:

UseWhenWhy
NodeFew nodes; current sources present A current source contributes a right-hand-side term directly — no extra work
MeshFew windows; voltage sources present A voltage source contributes a right-hand-side term directly

Count before you commit. A circuit with 4 nodes and 2 windows gives 3 node equations or 2 mesh equations — take the mesh. Reverse those numbers and take the node. That thirty-second count regularly saves three minutes.

Worked · the cast circuit as a matrix

Part 1 solved this with one KCL equation. Here it is in the matrix form, so the pattern is visible on a case you already know the answer to.

  1. Ground the bottom rail. There is exactly one unknown node — call it P — so the "matrix" is 1×1.
  2. Diagonal: every conductance touching P. G_P = 0.8333 S
  3. Right-hand side: the current the source pushes in, which for a voltage source behind a resistor is 100/2 = 50 A.
  4. V_P = 50/0.8333 = 60 V — the same 60 V as Part 1 and Part 2, by a method that would have worked just as well on a bridge.
Trap · the sign on the off-diagonal

Off-diagonal entries are negative, in both the node and the mesh matrix. The reason is physical, not conventional: a branch shared between two nodes carries current that leaves one and enters the other, so it appears with opposite signs in the two equations. If your matrix comes out with a positive off-diagonal, you have dropped a sign, and the answer will be wrong in a way that still looks plausible.

3.6 What to memorise from this part

Know cold

  • Node analysis: ground one node, KCL at the rest, currents written as (local node − other node)/R.
  • The conductance matrix by inspection: diagonal is the sum of conductances at the node, off-diagonal is minus the shared conductance.
  • Mesh analysis: clockwise loop currents, KVL round each; a shared resistor carries the difference.
  • Off-diagonal entries are negative in both methods.
  • Count unknowns before choosing. Nodes minus one, versus windows.
  • No ground means a singular matrix. Pick a reference first, always.

Node analysis is KCL written at every node at once; mesh analysis is KVL written round every window at once. Both turn a circuit into a linear system that a determinant can solve, and neither cares what the network looks like.

The system's matrix can be written straight off the drawing — diagonal is what touches that node or loop, off-diagonal is minus what is shared. That is the whole of the method, and it is why circuits are a linear algebra problem wearing a schematic.
