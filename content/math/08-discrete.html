Discrete Mathematics

Everything so far has been continuous — curves, fields, smooth change. This part is about things you can count, and it is the mathematics the Computer half of this exam runs on.

8.1 Sets, and the two operations

A set is a collection with no duplicates and no order. Two operations do nearly all the work: union (A ∪ B, everything in either) and intersection (A ∩ B, only what is in both).

8.2 Counting: does order matter?

Almost every counting question reduces to one decision, and getting it wrong is worth a whole factorial.

  • A permutation counts arrangements where order matters — first, second, third are different outcomes.
  • A combination counts selections where order does not matter — a committee is the same committee whichever way you list its members.

Plate 23 makes the division visible. Turn the knob and watch the slot diagram fill.

The killer number

Choose 3 components from a bin of 10. If you are assigning them to three labelled positions, there are 720 ways. If you are just grabbing three, there are 120. The factor between them is 3! = 6 — so misreading this one word puts your answer out by 600%, and both numbers will be sitting there among the four options.

Trap · finding the word that decides it

Read the stem for the giveaway. "Arrange", "order", "sequence", "first / second / third", "password", "line up" → permutation. "Choose", "select", "committee", "team", "subset", "sample" → combination. If the same three items in a different order would count as a different answer, it is a permutation.

8.3 Logic, and where it reappears

A proposition is a statement that is either true or false. Combine them with AND, OR and NOT and you can settle any question in this topic with a truth table — write out every combination of inputs and evaluate. For n inputs there are 2ⁿ rows, which is why nobody does this by hand past about four.

Trap · the converse is not the contrapositive

From p ⇒ q, the contrapositive ¬q ⇒ ¬p is always equally true. The converse q ⇒ p is a different claim and need not be true at all. "If it is raining, the ground is wet" does not mean "if the ground is wet, it is raining." Exam questions in this topic are usually testing exactly that distinction.

8.4 Graphs, and a matrix you have already met

A graph is a set of vertices joined by edges — a network. Routing tables, circuit topologies, state machines and dependency chains are all graphs, which is why this appears on an exam for electrical and computer engineers.

The vocabulary is small. The degree of a vertex is how many edges touch it. A graph is connected if you can get from any vertex to any other. A path visits vertices without repeating; a cycle is a path that returns to where it started.

And there is one fact worth carrying, because it is instant and the exam likes it:

A graph can also be written as a matrix. Put a 1 at row i, column j when vertices i and j are joined, and 0 otherwise: that is the adjacency matrix. Click the edges in Plate 24 and watch it fill in.

Part 5 comes back

The adjacency matrix is a real matrix, and matrix multiplication means something here: entry (i,j) of A² counts the two-step routes from i to j. The row-dot-column rule from Part 5 is doing exactly what it looks like — checking every intermediate vertex and counting the ones that connect through.

8.5 Recurrence relations

A recurrence relation defines each term of a sequence using earlier ones — the discrete cousin of a differential equation, and solved the same way. For a linear recurrence with constant coefficients, guess y_k = rᵏ, substitute, and you get a characteristic equation exactly as in Part 7.

The FE exam mostly asks you to verify a proposed solution rather than derive one, which is a gift: substitute each option into the recurrence and see which survives. That is four substitutions against one derivation, and it cannot go wrong.

8.6 What to memorise from this part

Know cold

  • Order matters → permutation n!/(n−r)!. Order does not → combination, the same thing over r!.
  • Combinations are always smaller. If your "choose" answer is bigger than your "arrange" answer, you have them backwards.
  • |A∪B| = |A|+|B|−|A∩B|.
  • De Morgan, in all three costumes: sets, logic, and logic gates.
  • The contrapositive is always true; the converse need not be.
  • Σdeg(v) = 2|E|, so odd-degree vertices always come in pairs.

Counting questions turn on one word: whether order matters. Permutation if it does, combination if it does not, and the two differ by exactly r!.

De Morgan's laws are one fact appearing in three notations. And a graph is a matrix in disguise, which means the machinery from Part 5 applies to networks without any translation.
